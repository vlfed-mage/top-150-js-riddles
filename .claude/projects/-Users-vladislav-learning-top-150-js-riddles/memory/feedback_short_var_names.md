Use short variable names (p1, p2, wp) instead of verbose names (pointer1, pointer2, writePointer) in algorithm solutions.

**Why:** User finds long names unnecessary for algorithm code where context is clear.

**How to apply:** When writing LeetCode solutions, use concise variable names — especially for pointers and loop indices.
